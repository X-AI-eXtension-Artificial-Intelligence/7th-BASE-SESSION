
1. 데이터 준비 단계 (load_data.py 역할)
모델이 학습할 수 있는 숫자 형태(Tensor)로 가공하는 역할

텍스트 정제: 대문자를 소문자로 바꾸고, 특수문자를 분리하며, 유니코드 문자를 ASCII로 변환

단어 사전 구축: Lang 클래스를 통해 단어마다 고유한 번호(Index)를 부여

데이터 필터링: 특정 접두사(예: "I am", "He is")로 시작하는 짧은 문장들만 골라내어 모델이 학습하기 쉬운 환경 생성

배치 처리: 여러 개의 문장을 묶어서 한 번에 학습할 수 있도록 DataLoader를 생성하고, 문장 길이를 맞추기 위한 패딩(Padding) 및 마스킹(Masking) 처리를 수행.

2. 모델 설계 단계 (model.py 역할)
입력된 문장을 이해하고 새로운 언어로 출력하는 두뇌의 구조를 정의.

Encoder (인코더): 입력된 영어 문장의 의미를 수치화된 벡터로 압축.

Attention (어텐션): 이 시스템의 핵심입니다. 번역할 때 입력 문장의 특정 단어에 더 집중

Decoder (디코더): 인코더가 준 정보와 어텐션의 도움을 받아 프랑스어 단어를 하나씩 생성.

3. 학습 및 실행 단계 (main.py 역할)
설계된 모델에 데이터를 흘려보내 학습시키고 실제 결과를 확인하는 단계

학습 루프 (Training): 모델이 예측한 값과 실제 정답(프랑스어)을 비교하여 오차(Loss)를 줄여나갑니다. 이 과정에서 Adam 옵티마이저를 사용하여 가중치를 조절.

추론 (Inference): 학습이 끝난 모델에게 새로운 문장을 주고, Greedy Decode 방식(가장 확률 높은 단어를 선택하는 방식)으로 번역을 수행.

결과 출력: 입력된 영어, 실제 정답, 모델이 번역한 결과를 텍스트로 보여주어 성능을 육안으로 확인.
