📂 폴더 구조 및 업로드 방식
파일 위치: 해당 주차의 코드 폴더 내에 자신의 코드 파일을 바로 업로드해 주세요.
주의사항: 개인 이름 폴더 안에 또 다른 하위 폴더를 만들지 않습니다.
✅ Good: U-Net/이은진/main.py
❌ Bad: U-Net/이은진/u-net/main.py
⚠️ 데이터 파일 업로드 금지
데이터셋 및 로그: 용량이 큰 데이터 파일(.csv, .zip, .pkl 등)이나 실행 로그 파일은 깃허브에 업로드하지 마세요.
이유: 깃허브 저장소 용량 초과 및 속도 저하의 원인이 됩니다.
