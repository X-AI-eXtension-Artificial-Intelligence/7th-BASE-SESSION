# Vision Transformer (ViT) - 실행 가이드

## 환경 요구사항

- Python 3.8 이상
- GPU 권장 (없어도 CPU로 실행 가능, 단 느림)

---

## 빠른 시작

### 1단계: 패키지 설치

```bash
pip install torch torchvision matplotlib
```

> `requirements.txt`의 버전(torch 1.13.1)은 구버전이지만, 최신 버전도 정상 동작함.

### 2단계: 모델 동작 확인 (선택)

```bash
python3 -c "
import torch
from vit import ViTForClassfication

config = {
    'patch_size': 4, 'hidden_size': 48, 'num_hidden_layers': 4,
    'num_attention_heads': 4, 'intermediate_size': 192,
    'hidden_dropout_prob': 0.0, 'attention_probs_dropout_prob': 0.0,
    'initializer_range': 0.02, 'image_size': 32, 'num_classes': 10,
    'num_channels': 3, 'qkv_bias': True, 'use_faster_attention': True,
}
model = ViTForClassfication(config)
out, _ = model(torch.randn(2, 3, 32, 32))
print('✅ 성공! output shape:', out.shape)
print('파라미터 수:', sum(p.numel() for p in model.parameters()))
"
```

### 3단계: 학습 실행

```bash
# 기본 실행 (100 에폭, 논문 설정)
python train.py --exp-name vit-cifar10 --epochs 100 --batch-size 256 --lr 0.01

# 빠른 테스트 (5 에폭)
python train.py --exp-name vit-quick-test --epochs 5 --batch-size 256

# GPU 지정
python train.py --exp-name vit-gpu --epochs 100 --batch-size 256 --device cuda

# 체크포인트 저장 (10 에폭마다)
python train.py --exp-name vit-with-ckpt --epochs 100 --save-model-every 10
```

> CIFAR-10 데이터셋은 첫 실행 시 `./data/` 폴더에 자동으로 다운로드됨. (~170MB)

## 파일 구조

| 파일 | 설명 |
|------|------|
| `vit.py` | ViT 모델 구현 (핵심 코드) |
| `train.py` | 학습 스크립트 및 모델 config |
| `data.py` | CIFAR-10 데이터 로더 |
| `utils.py` | 저장/로드, attention 시각화 |

| `vision_transformers.ipynb` | ViT 구조 설명 노트북 |

---

## 모델 구조 요약

```
입력 이미지 (32x32x3)
    ↓
Patch Embedding (4x4 패치 → 64개 패치)
    ↓
[CLS] 토큰 추가 + Position Embedding
    ↓
Transformer Encoder × 4 레이어
  ├─ Multi-Head Self-Attention (4 헤드)
  └─ MLP (hidden_size 48 → 192 → 48)
    ↓
[CLS] 토큰 → Linear Classifier
    ↓
10개 클래스 예측

---

## 주의사항

- CPU만 있는 경우 100 에폭 학습에 수 시간이 걸릴 수 있음
- GPU(CUDA) 사용 시 약 30~60분 소요
- `torchvision` 최신 버전에서는 `transforms.Resize` 관련 경고가 나올 수 있으나 동작에는 문제없음
