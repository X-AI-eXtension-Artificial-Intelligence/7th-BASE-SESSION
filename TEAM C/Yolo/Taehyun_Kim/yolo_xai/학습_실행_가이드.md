# YOLO v1 PyTorch 구현 — 학습 실행 가이드

## 전체 파일 구조 및 역할

```
yolov1/
├── model.py          ← 신경망 구조 정의
├── dataset.py        ← VOC 데이터셋 로더
├── transforms.py     ← 데이터 전처리 및 증강
├── loss.py           ← YOLO 손실 함수
├── train.py          ← VOC 탐지 학습 메인
├── pretrain.py       ← ImageNet 사전학습 메인

├── plot_predictions.py ← 예측 시각화
└── requirements.txt  ← 패키지 목록
```

## 모듈별 역할 설명

### `model.py` — 신경망 구조
YOLO v1의 전체 모델을 구현한다.
- **`LocallyConnected2d`**: 위치별 독립 가중치를 사용하는 레이어. 일반 Conv2d는 모든 위치가 같은 가중치를 공유하지만, 이 레이어는 각 위치마다 고유한 가중치를 가진다. 논문의 첫 번째 FC 레이어 대신 사용.
- **`ConvModule`**: 설정(config)을 받아 Conv/MaxPool 레이어들을 자동으로 쌓는 모듈. `('c', 3, 64)` 같은 튜플로 레이어를 선언형으로 정의할 수 있다.
- **`YOLOv1`**: 전체 모델.
  - `'classification'` 모드: ImageNet 사전학습용 (Backbone + AvgPool + Linear)
  - `'detection'` 모드: VOC 탐지용 (Backbone + Detection Head)
  - 출력: `(N, S, S, C + B×5)` — 각 셀마다 C개 클래스 확률 + B개 박스×5개 값

### `dataset.py` — 데이터셋 로더
PASCAL VOC 데이터셋을 PyTorch Dataset 형식으로 제공한다.
- 이미지(`.jpg`)와 어노테이션(`.csv`)을 매핑하여 로드
- 어노테이션 형식: `class, xmin, ymin, xmax, ymax`
- 클래스 이름 ↔ 인덱스 변환, 시각화 색상 테이블 제공

### `transforms.py` — 전처리 & 데이터 증강
파이프라인 형태로 연결되는 변환 클래스 모음.

| 클래스 | 역할 |
|---|---|
| `Resize` | 이미지를 d×d로 리사이즈, 박스 좌표 스케일링 |
| `RandomScaleTranslate` | 리사이즈 / Zoom In / Zoom Out 중 랜덤 선택 (주요 공간 증강) |
| `RandomColorJitter` | HSV 색공간에서 색조·채도·노출 랜덤 조정 |
| `RandomHorizontalFlip` | 확률적 수평 반전 |
| `ToYOLOTensor` | 이미지→Tensor, 박스 좌표→YOLO 그리드(S×S×(C+5)) 변환 |
| `ImgToTensor` | 이미지만 Tensor로 변환 (evaluate.py 전용) |

모든 클래스는 `(image, mask, target)` 튜플을 입출력으로 사용하며, **mask**는 제로 패딩된 영역을 제외하고 정규화할 실제 이미지 영역을 지정한다.

### `loss.py` — YOLO 손실 함수
YOLO v1의 핵심 손실 함수를 구현한다.

**손실 = 위치 손실(×5) + 신뢰도 손실 + 분류 손실**

- **위치 손실**: 담당 박스의 중심 좌표(x, y)와 크기(√w, √h) 오차. √를 직접 예측해 작은 박스의 오차를 더 강하게 반영하고 gradient 발산을 방지.
- **신뢰도 손실**: 담당 박스는 목표 confidence = 실제 IoU, 나머지 박스는 목표 = 0 (×0.5 가중치로 억제).
- **분류 손실**: 객체가 있는 셀에서만 클래스 예측 오차 계산.

B개의 박스 중 정답과 **IoU가 가장 높은** 박스가 해당 셀의 예측을 담당(Responsible)한다.

### `train.py` — 학습 메인
탐지 모델 학습의 전체 흐름을 관장한다.
- **`MultiStepScaleLR`**: 커스텀 학습률 스케줄러. Burn-in(초기 점진적 증가) + 지정 스텝에서 배율 조정.
- **그래디언트 누적(Gradient Accumulation)**: `BATCH=64, SUBDIVISIONS=8`이면 8장씩 8번 forward/backward 후 1번 update → 메모리 절약하면서 64장 배치 효과.
- **체크포인트**: `CHECKPOINT_T` 에폭마다 저장. 학습 중단 후 `LOAD_MODEL='train'`으로 재개 가능.

### `pretrain.py` — ImageNet 사전학습
YOLO backbone을 ImageNet으로 사전학습한다.
- 분류 모드(`mode='classification'`)로 모델 생성
- SGD + ReduceLROnPlateau 스케줄러
- Top-1 / Top-5 정확도 측정 (논문: Top-5 88%, 이 구현: 89%)

### `evaluate.py` — mAP 평가
학습된 탐지 모델을 VOC 테스트셋으로 평가한다.
- **후처리 파이프라인**: 좌표 역정규화 → confidence 필터링 → NMS
- **mAP 계산**: 클래스별 precision-recall 곡선 보간 후 AP 계산

## 학습 실행 전 준비

### 1. 환경 설치

```bash
pip install torch==1.11.0+cu113 torchvision==0.12.0+cu113 \
    tqdm matplotlib pillow \
    -f https://download.pytorch.org/whl/torch_stable.html
```

### 2. 데이터셋 준비

#### PASCAL VOC (탐지 학습용)
```bash
# 데이터 다운로드 및 정리 스크립트 실행 (README 참고)
./download_voc.sh
./organize_voc.sh
python3 simplify_voc_targets.py
```

최종 디렉토리 구조:
```
VOC_Detection/
├── train/
│   ├── images/     ← .jpg 파일들
│   └── targets/    ← .csv 어노테이션 파일들
└── test/
    ├── images/
    └── targets/
```

#### ImageNet (사전학습용, 선택)
ImageNet 공식 사이트 가입 후 다운로드 → `./organize_imagenet.sh` 실행

`train.py`에서 다음 경로를 본인 환경에 맞게 수정:

```python

TRAINING_CHECKPOINT_PATH  = "/your/path/checkpoints/training_checkpoint.pt"
TRAINED_MODEL_WEIGHTS     = "/your/path/checkpoints/trained_model_weights.pt"
```

## 학습 실행

### 방법 1: 사전학습 가중치로 시작 (권장)

`train.py`에서:
```python

PRETRAINED_MODEL_WEIGHTS = "/path/to/pretrained_model_weights.pt"
```

```bash
python3 train.py
```

### 방법 2: 처음부터 학습 (Scratch)

```python
LOAD_MODEL = None
```

```bash
python3 train.py
```

### 방법 3: 중단된 학습 재개

```python
LOAD_MODEL = 'train'
TRAINING_CHECKPOINT_PATH = "/path/to/training_checkpoint.pt"
```

```bash
python3 train.py
```

### ImageNet 사전학습 (선택)

```bash
# pretrain.py에서 TRAIN_MODEL = True로 설정 후:
python3 pretrain.py
```

## 주요 하이퍼파라미터 설명

| 파라미터 | 기본값 | 설명 |
|---|---|---|
| `S` | 7 | 그리드 분할 수 (7×7=49셀) |
| `B` | 2 | 셀당 예측 박스 수 |
| `D` | 448 | 입력 이미지 크기 (픽셀) |
| `L_COORD` | 5.0 | 위치 손실 가중치 |
| `L_NOOBJ` | 0.5 | 비객체 confidence 손실 가중치 |
| `BATCH` | 64 | 논리적 배치 크기 |
| `SUBDIVISIONS` | 8 | 그래디언트 누적 횟수 (실제 미니배치=8장) |
| `MAX_EPOCHS` | 156 | 총 학습 에폭 |
| `INIT_LR` | 0.0005 | Burn-in 완료 후 목표 학습률 |
| `BURN_IN` | 100 | 초기 학습률 워밍업 스텝 수 |
